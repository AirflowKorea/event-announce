# 행사 자원봉사자 업무 분장 안내

Airflow KRUG 행사 업무 안내 웹페이지입니다.

## 📁 페이지 구성
- `index.html`: 메인 페이지 (공통 공지, 5F 안내도 및 파트별 업무 요약)
- `flow.html`: 시간대별 참가자 이동 동선 시뮬레이션 (JS 애니메이션)
- `roles/`: 파트별 상세 안내 가이드
  - `photo.html` (사진)
  - `reception.html` (리셉션)
  - `stage.html` (발표)
  - `floor.html` (현장)
  - `media.html` (미디어)
